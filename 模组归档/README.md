# 模组归档

mcmcp 的仓库（modId: commhub）各版本打包好的 jar 归档。

## 目录结构

**所有版本的 jar 直接放在本目录下，不再分 `正式版/`、`测试版/` 子目录。**

（早期 1.0.0 之前分过这两个目录，但之后每版都进正式版，分法就没意义了，已合并到本目录；jar 一个没删。）

## 归档规则

- 每个版本交付后，jar 都归档一份到这里，**不删除**，历史可追溯
- 只归档**打包好的 jar**，不归档源码（源码在上级 `mcmcp的仓库源码/` 目录）
- **根目录只放最新一版 jar**，旧版本只在这里备份

## 版本号规则

格式固定为 `1.<大更新序号>.<本轮修bug次数>`：

| 事件 | 变化 | 例子 |
|---|---|---|
| 一次大更新（加功能） | 中间位 +1，**末位清零** | 1.9.7 → **1.10.0** |
| 一次修 bug | 末位 +1 | 1.9.6 → 1.9.7 |
| 末位不进位 | 本轮修 N 个 bug 就是 `.N` | 本轮修 20 个 = 1.9.20 |
| 修 bug 计数只在本轮累计 | 下次大更新时归零 | 1.9.20 → 1.10.0 |

> 例：第 10 次大更新后、那一轮修了 20 个 bug → `1.10.20`
>
> 当前：`1.9.7`（第 9 次大更新后的第 7 个 bug 修复）；下一次大更新为 `1.10.0`
