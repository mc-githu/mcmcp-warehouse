# v1.11.23 更新日报

**日期**：2026-10-08
**类型**：修复（没私人仓库就打不开界面）
**jar**：`mcmcp_warehouse-1.11.23.jar`

## 问题（用户指出）

> 「如果没有私人仓库就无法打开，可是邮箱还有以物换物的是免费的，所以不行，
>   应该只是不能使用私人仓库而已。」

完全正确。共享大仓库默认关闭后，我把「打开界面」的前置条件写成了"必须有私人仓库"：

```java
if (!sharedEnabled) {
    if (list.isEmpty()) {
        player.sendSystemMessage("...你还没有私人仓库...");
        return;          // ← 界面直接打不开 ✗
    }
    ...
}
```

但**邮箱（传物品）、以物换物、私聊都是免费功能**，不该被私人仓库卡住 ✗

## 修复：界面永远能打开，只是那一页不可用

`handleOpenHub` 改成按「能用哪个用哪个」的顺序挑页面：

| 顺序 | 条件 | 打开 |
|---|---|---|
| ① | 上次看的私人仓库还有权限 | 那个私人仓库 |
| ② | 上次看的是私聊 / 传物品 | 对应页 |
| ③ | 上次看的是共享，且共享开着 | 共享大仓库 |
| ④ | 有私人仓库 | 第一个私人仓库 |
| ⑤ | 共享开着 | 共享大仓库 |
| ⑥ | **都没有** | **传物品页（邮箱免费）** ✅ |

- 没私人仓库时点「私人仓库」标签 → 只提示「你还没有私人仓库，先用管理员凭证创建一个」，
  **界面继续开着**，别的页照样用
- 顺手把「打开共享页」的代码抽成 `openSharedHub()`，逻辑更清楚

## 安装
按用户新规矩：**只装 `模组测试` 实例**，其他实例一律不动。
