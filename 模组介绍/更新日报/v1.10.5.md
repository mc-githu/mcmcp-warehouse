# v1.10.5 更新日报

**日期**：2026-10-07
**类型**：调整（配置入口）
**jar**：`mcmcp_warehouse-1.10.5.jar`

## 改动

按最新的设计定稿调整：

| 项 | 之前 | 现在 |
|---|---|---|
| 打开配置界面 | 卡槽里放了卡后，界面出现「添加」按钮 | **拿着卡右键空气**直接打开（不占仓库界面空间） |
| 卡槽 | 私人仓库 3 格 | **私人仓库 3 格**（不变） |
| 共享仓库 | 没有卡槽 | 没有卡槽（不变） |

使用流程变成：

1. 合成「合成升级卡」
2. **拿着卡右键空气** → 配置界面里设 5 个目标（JEI 拖拽 / 左键放 / 右键清空、滚轮翻列表）
3. 保存后把卡放进**私人仓库的卡槽**（最多 3 张）
4. 仓库就会按卡上的配方自动合成（材料从仓库取、产物放回、不够就停）

顺带：仓库界面右侧的「添加」按钮和相关代码已移除，卡槽位置只保留金色框。
