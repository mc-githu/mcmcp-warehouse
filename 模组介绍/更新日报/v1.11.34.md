## 用户反馈（附截图）
> 「还是没连到我这，并且这个链应该有动的动画，并且这个按键为什么还是横着的？把它竖着」

## 根因：坐标系用错了
原来我把锁链方向按**实体朝向**算（`-e.getYRot()`），但矩形是画在**朝向摄像机**的平面里的 ✗
两套坐标系不一致 → 锁链就落到莫名其妙的位置（截图上是一条横躺在地上的小点）✗

## 改法：每个链节都在**自己的世界坐标**上画
```java
for (int i = 0; i <= n; i++) {
    Vec3 wp = from.add(dir.scale(f));          // 世界坐标上的这一节
    pose.pushPose();
    pose.translate(wp - entityPos);            // 转到实体本地
    pose.mulPose(cameraOrientation());         // 每节各自朝向摄像机
    quad(..., -0.07f, -0.15f, 0.07f, 0.15f);   // ← 竖着的链节
    pose.popPose();
}
```
这样：
- 锁链**一定从裂缝连到玩家**（用玩家胸部位置做终点）✓
- 链节是**竖的**（0.14 × 0.30，细长竖条）✓
- **有流动动画**：`flow = tickCount * 0.10`，链节沿锁链往裂缝方向移动 ✓
