## 2. 管理工具：**只认已绑定的**（用户报「没绑定哪来的」）
> 「明明是送那个管理员转让工具，为什么其他两个添加成员和减去成员的也会自己送，
>   本来是需要绑定的」

根因在 `matchesWarehouse()`：
```java
// 旧写法：未绑定的也算（可以拉回来重新绑）
return wh.isEmpty() || wh.equals(whName);
```
→ 「重置工具」会把**从没绑定过**的工具也一起扫走 ✗

改成：
```java
// 只认已经绑定到这个仓库的；没绑定的不属于任何仓库，系统不该动它
return !wh.isEmpty() && wh.equals(whName);
```

## 3. 悬赏可以取消了（用户报「为什么不能取消」）
- 换物模式里，**自己发的**悬赏标注「（我的，可取消）」，按钮变成 **「取消悬赏」**
- 服务端校验：**只有发布者本人**能取消 ✓
- 取消后立刻广播，所有人列表刷新 ✓
