## 一、以物换物成交动画：空间裂缝 + 锁链 + 箱子

成交（接受悬赏）成功时，**双方各播两段动画**（先"送出去"、再"收进来"），
以物换物是双向的，所以正好对应"传过去 + 传回来"。

**时间轴（每段约 2.3 秒）**：
```
0    ~ 0.38s  空间裂缝张开
0.38 ~ 0.78s  锁链从裂缝伸出
0.78 ~ 1.56s  箱子沿着锁链被拉进裂缝（或从裂缝送出来）
1.56 ~ 1.86s  锁链收回
1.86 ~ 2.26s  裂缝关闭
```

**素材**（按用户要求）：
| 元素 | 来源 |
|---|---|
| 铁链 | **原版** `minecraft:textures/item/chain.png`（沿路径一节节铺，横竖交替） |
| 箱子 | **机械动力**的纸箱贴图 `create:block/cardboard_block_side`（装了 Create 才用；没装用模组自带的），箱子中间还会显示**被交换物品的图标** |
| 空间裂缝 | **模组自己画的** `assets/commhub/textures/gui/rift.png`（紫黑竖椭圆 + 边缘发光） |

**裂缝里面**：
- **星辰**：90 颗伪随机星点，随时间缓慢漂移 ✓
- **看不到头的锁链**：14 节向深处收敛的链节（越往里越小越暗），像通向虚空 ✓

**跟随玩家**：裂缝和锁链会跟着玩家动 ——
- 转身（水平朝向）→ 左右摆动
- 移动（速度）→ 反向拖拽，有"被拽住"的感觉

## 二、调试指令：关掉「不能接受自己的悬赏」（OP 专用）

```
/commhub selftrade          # 切换开关
/commhub selftrade true     # 关闭限制（可以自己接受自己的悬赏）
/commhub selftrade false    # 打开限制（默认）
```

- **只有 OP（权限等级 2）能用** ✓
- 默认**开启**限制（正常玩法不能自己接受自己的悬赏）
- 关掉后接受自己的悬赏会正常成交，用于调试动画/流程

## 三、修编译错误
`TradeEffect` 的 codec 用了 `ItemStack.STREAM_CODEC`，它需要 `RegistryFriendlyByteBuf`
→ 改成 `RegistryFriendlyByteBuf` + `ItemStack.OPTIONAL_STREAM_CODEC` ✓
