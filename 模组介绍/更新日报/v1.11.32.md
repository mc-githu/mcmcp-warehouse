## 用户反馈
> 「锁链怎么是竖着的？而且为什么没有锁定到我身上？」

## 1. 锁链全是竖的
用的是原版链子的**物品图标**（`minecraft:textures/item/chain.png`），
它本身就是**竖着的**一节链环 ✗ 我原来只是把贴图「拉宽」想让它变横 —— 结果看着还是竖的 ✗

**改法**：横的那一节用**旋转 90°** 画（`pose.mulPose(Axis.ZP.rotationDegrees(90))`），
和竖的一节交替 → 正常的锁链外观 ✓

## 2. 锁链没有"锁到玩家身上"
链子的近端原来被我固定在**屏幕右下角** ✗ —— 和玩家没关系。

**改法**：近端改成**屏幕正下方**（玩家身体的位置），并且**跟着玩家的摆动一起动**：
```java
int fromX = w / 2 + (int) (swayX * 1.6f);   // 跟随转身/移动
int fromY = h - 40 + (int) swayY;
```
配合原来的 sway，现在看起来就是「**锁链从我身上伸出去、被我拽着动**」✓
