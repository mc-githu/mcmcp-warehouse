# v1.11.43 更新日报

**日期**：2026-10-09
**类型**：修复（自查出的 bug：锁链碰撞体从未生成）
**jar**：`mcmcp_warehouse-1.11.43.jar`

## 自查发现的 bug
```java
// RiftRenderer.render()  ← 渲染只在【客户端】执行
if (!e.level().isClientSide) e.spawnChainNodes();   // ← 永远不成立 ✗
```
→ **链节碰撞体一次都没生成过** ✗
也就是说：之前说好的「锁链也有碰撞体积」**实际上一直没生效** ✗

## 修复
把生成挪到**实体的 tick（服务端）**，并且只做一次：
```java
if (!level().isClientSide && !isChainNode() && !nodesSpawned) {
    nodesSpawned = true;
    spawnChainNodes();
}
```
- 主裂缝一出生就在服务端摆好 4 个链节（0.45×0.45 碰撞箱）
- 链节每 tick 贴到「裂缝中心 → 最近玩家胸口」这条线上，跟着锁链动 ✓
- 主裂缝回收时链节一起消失 ✓
- 渲染器里那句无效调用删掉 ✓

## 教训
**渲染代码（客户端）里不要写服务端逻辑** —— 这次就是写错了执行侧 ✗
以后凡是"生成实体/改世界"这类操作，一律放服务端（tick 或事件）✓
