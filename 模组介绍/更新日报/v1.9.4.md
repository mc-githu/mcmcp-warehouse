# v1.9.4 更新日报

## 修复

**sable 2.0.3 + flywheel 兼容性崩溃**

- 现象：渲染世界时崩溃
  ```
  java.lang.NullPointerException: Cannot invoke "ObjectArrayList.get(int)" because "this.wrapped" is null
    at flywheel BlockEntityStorage.sable$updateSubLevelEmbeddingsFrame
    at LevelRenderer.renderLevel
  ```
- 原因：sable 遍历子级别块实体时，`posLookup.get()` 对**没有 flywheel visual 的块实体**返回 null，随后 `checkcast` 直接 NPE（与 commhub 无关，是 sable 的判空缺失）
- 处理：mod 内置 Mixin 补丁 `SableFlywheelCrashFixMixin`
  - `@Mixin` 到 flywheel 的 `BlockEntityStorage`
  - 用 `@WrapMethod` 包住 sable 注入的 `sable$updateSubLevelEmbeddingsFrame` / `sable$preFlywheelFrame`
  - 异常时跳过该帧，不再崩整个游戏
