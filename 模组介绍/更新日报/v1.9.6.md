# v1.9.6 更新日报

**日期**：2026-10-07
**类型**：修复 + 界面
**jar**：`mcmcp_warehouse-1.9.6.jar`

## 修复

### 手册打不开
日志原因：
```
Failed to load book commhub:commhub_guide: Book has use_resource_pack set to false.
This behaviour was removed in 1.20. The book author should enable this flag
and move all book contents clientside to /assets/, leaving the book.json in /data/.
```
处理（Patchouli 1.20+ 规范）：
- `data/commhub/patchouli_books/commhub_guide/book.json` + `"use_resource_pack": true`
- 书内容移到 `assets/commhub/patchouli_books/commhub_guide/{zh_cn,en_us}`
- 配方图放在 `assets/commhub/textures/`

### 管理员工具一拿就消失
- 原因：`SlotItemHandler.set()` 会 `checkcast IItemHandlerModifiable` 并调 `setStackInSlot`，而工具格子的 `ArrayToolHandler` 只实现了 `IItemHandler` → 服务端抛 `ClassCastException` 导致物品丢失（客户端用的是可修改的 `ItemStackHandler`，所以只有服务端出问题）
- 处理：`ArrayToolHandler` 改为实现 `IItemHandlerModifiable`
