## 2. 版本兼容性：真的测了

之前我们**编译时用的是 JEI 19.57**，而整合包装的是 **19.27** —— 版本差挺多，属于风险点。
（JEI 的 API 在小版本间会变，编译期能过不代表运行期能过，典型错误就是 `NoSuchMethodError` 崩溃。）

**做法（这是我能自己做的实测）**：
1. 把整合包里那个 **19.27 的 jar 直接拿来当编译依赖**
2. 用它重新编译我们的 mod

→ **编译成功** ✅ 说明我们用的那 5 个 API 在 19.27 里全都在、签名也一致。

具体核对的 API：

| 用到的 API | 19.27 里 |
|---|---|
| `IModPlugin` / `JeiPlugin` | ✅ |
| `IGuiHandlerRegistration.addGhostIngredientHandler` | ✅ |
| `IGhostIngredientHandler.getTargetsTyped` / `onComplete` | ✅ |
| `IGhostIngredientHandler.Target.getArea/accept` | ✅ |
| `ITypedIngredient.getItemStack()` → `Optional<ItemStack>` | ✅（两版都是 Optional，**签名一致**） |
| `IRecipeRegistration.addItemStackInfo` | ✅ |

以后 **build.gradle 就固定用 19.27 编译**，这样"编译能过"就等于"在你整合包里能跑"。
