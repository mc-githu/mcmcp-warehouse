# v1.10.0 更新日报

**日期**：2026-10-07
**类型**：**大更新**（新功能：合成升级卡 / 仓库自动合成）
**jar**：`mcmcp_warehouse-1.10.0.jar`

## 新功能：合成升级卡

给仓库加一张「合成升级卡」，装进仓库界面后，仓库会**自动按卡上的配方合成**，材料直接从仓库里扣。

### 怎么用

1. 合成一张 **合成升级卡**（配方：纸 ×4 + 铁板/铁锭 ×4 + 工作台）
2. 把卡放进**私人仓库界面右侧的卡槽**（**最多 3 张**；只有私人仓库有卡槽，共享仓库没有）
3. 卡槽里放了卡之后，界面会出现 **「添加」按钮** → 点开配置界面
4. 在配置界面里：左侧是**目标列表**（装了几张卡就有几组，每组 5 个目标），
   右侧是编辑区 —— **3×3 配方幽灵格 + 产物幽灵格**
   - 支持 **JEI 直接拖拽**物品进格子
   - 左键格子 = 放手持物品，右键 = 清空
   - 目标多了列表放不下时，**鼠标滚轮上下翻**
5. 点「保存」写回卡片

### 自动合成规则

- 每 **10 tick（约 0.5 秒）** 每个仓库合成一次
- 材料**从仓库里取**（共享仓库 / 对应私人仓库）
- 产物**放回仓库**
- **材料不够 → 自动跳过（停下）**，不会半途扣一半材料
- 配方必须能在合成表里找到（防止自定义出"凭空造物"的配方）
- 容器返还（桶、瓶子之类）也会放回仓库

### 界面改造

- 仓库界面新增 **3 个卡槽**（金色框），与已有的管理工具栏（红色框）区分开
- 卡槽里放了卡才出现 **「添加」** 按钮
- 配置界面也做了分区框：目标列表（黄）、配方区（青）、产物区（金）、按钮区（黄）、说明区（灰）

### 权限

- 只有**私人仓库**有卡槽，且只有**主人或管理员**能放进/拿走卡片、能配置
- 共享大仓库没有卡槽（自动合成不会跑）
