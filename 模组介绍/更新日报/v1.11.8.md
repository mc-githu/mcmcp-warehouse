## 2. 修复：多张卡时第一张没材料，后面的卡也不干活
`tickSaw`（动力锯）里材料不够 / 仓库放不下时用的是 `return false` ——
这会**直接结束这一轮**，导致后面卡槽里的卡**这一轮也不跑**。

改成（带标签的循环）：
```java
cards:
for (ItemStack card : cardSlots) {
    ...
    if (countOf(wh, in) < 1) continue cards;   // 只跳过这一张，继续处理后面的卡
}
```
