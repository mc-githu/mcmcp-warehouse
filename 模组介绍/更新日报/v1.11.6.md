# v1.11.6 更新日报

**日期**：2026-10-08
**类型**：平衡性调整（自动化核心改成「模板式」获取）
**jar**：`mcmcp_warehouse-1.11.6.jar`

## 改动

自动化核心原来是合成的（黑曜石 + 钻石 + 精密构件），太容易量产。
现在改成**下界合金升级模板**那种获取方式：

### 1. 删掉原合成配方
原来的 `automation_core` 合成配方（含原版兜底）**已删除**。

### 2. 只能在遗迹宝箱里找到
用 NeoForge 的**全局战利品修改器**（纯 JSON，不写代码）把核心加入这些宝箱：

| 类别 | 宝箱 |
|---|---|
| 地下 | 地牢、废弃矿井、试炼密室 |
| 沙漠/丛林/雪原 | 沙漠神殿、丛林神庙、雪屋 |
| 大型结构 | 林地府邸、掠夺者前哨、要塞（走廊/交叉口/图书馆） |
| 水下 | 沉船宝藏、埋藏的宝藏 |
| 下界/末地 | 下界要塞、堡垒遗迹（4 种）、远古城市、末地城 |

每个宝箱 **20% 概率**出现 1 个（权重 1 : 空 4）。

### 3. 复刻配方（一次复刻出 1 个）
| 位置 | 材料 |
|---|---|
| 正中 | **自动化核心** ×1 |
| 正上方 | **下界合金锭** ×1 |
| 其余 7 格 | **钻石** ×7（把核心包起来） |
| 产出 | **自动化核心 ×2**（等于复刻出 1 个） |
