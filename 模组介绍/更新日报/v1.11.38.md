## 改动

### 1. 锁链：改成**原版铁链方块模型**
原来是用 `chain.png` 贴图画矩形 ✗ → 现在用
`Minecraft.getBlockRenderer().renderSingleBlock(Blocks.CHAIN.defaultBlockState(), ...)`
渲染**真正的 3D 铁链方块模型** ✓
并且按链子走向自动设置 `ChainBlock.AXIS`（Y / X / Z）→ 链环方向跟着链子走 ✓
链节实体（碰撞体）也改用同一个方块模型 ✓

### 2. 空间裂缝：单片 → **十字交叉多层**
原来只有一张平面（侧着看就是一条线 ✗）→ 现在绕 Y 轴 **0°/45°/90°/135° 交叉 4 层**：
- 看起来是一团**有体积**的裂缝，而不是一张纸 ✓
- 星空也画在这 4 层上 → 从各个角度看都有星空 ✓
- 仍然是**双面可见**（不会随视角消失）✓

### 3. 包裹：继续用**机械动力的包裹模型**（本来就是 3D）
`create:package` 物品模型 ✓，上方显示内容提示（最多 3 样 + `…`）✓

## ⚠️ 流程坑（记下来，以后别再犯）
这一版第一次 `gradle build` **判定为 up-to-date**（因为只改了版本号，源码没变），
结果**没有产出新 jar**，我却把旧的 1.11.37 装了上去 ✗

**以后改版本号后必须强制重建**：
```bash
gradle build --no-daemon --rerun-tasks --init-script init.gradle
```
装之前**先确认 `build/libs/mcmcp_warehouse-<新版本>.jar` 真的存在**，再拷贝 ✓
