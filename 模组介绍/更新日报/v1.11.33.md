# v1.11.33 更新日报

**日期**：2026-10-09
**类型**：重做（成交动画 → 真正的**动态结构**）+ 调试指令
**jar**：`mcmcp_warehouse-1.11.33.jar`

## 用户要求
> 「要是动态结构，有碰撞箱」
> 「从空间裂缝后面看是什么都没有的，到前面才能看到星空；走到那块像撞墙；只能看到锁链，可以绕过去」
> 「只是看动画为什么非要以物换物？都是调试了」
> 「用机械动力的包裹模型，不要只画一个箱子；里面物品的图标别太大，把包裹都盖住了」

## 1. 裂缝做成**真实体**（不再是屏幕贴图）
新增：
- `ModEntities` / `RiftEntity` / `RiftRenderer`
- **碰撞箱 1.8 × 2.8** ✓（`canBeCollidedWith` / `isPickable` / `isPushable` 都开了 → 能撞、能推、能选中，走过去像撞墙）
- 能**绕过去**（不是方块，只是一块有体积的实体）

## 2. 裂缝是**单面**的
- 用**固定朝向**（生成时朝向玩家）+ `RenderType.entityCutout`（**背面剔除**）
- **正面**：看到裂缝本体 + **星空**（70 颗星点画在同一个平面上）
- **背面**：什么都看不到 ✓
- **锁链和包裹**仍然朝向摄像机 → 任何角度都看得见 ✓

## 3. 包裹用**机械动力的模型**
- 直接渲染 `create:package`（Cardboard Package）这个**物品模型** ✓
- 没装 Create 时退回模组自带贴图 ✓
- 里面装什么的图标**改小**（0.006 → 0.014 的缩放并移到包裹上方），不再盖住包裹本体 ✓

## 4. 调试指令：**不用以物换物也能看**
```
/commhub rift         # 开一个常驻裂缝（锁链一直伸着），直到 riftstop
/commhub rift stop    # 收掉所有裂缝
/commhub rift play    # 放一段「收进来」的完整动画（2.6 秒自动关）
/commhub rift play out # 放一段「送出去」的动画
```
全部 **OP（等级 2）** 专用 ✓；`play` 用你**手持的物品**当包裹里的东西 ✓
