## 一、自动化卡片（3 张卡）

都用同一种玩法：**拿着右键空气**配置 → 放进**私人仓库的卡槽**（最多 3 张）→ 仓库每约 **0.5 秒**自动干一次活。
材料从仓库取、产物放回仓库，材料不够就停。

| 卡片 | 配置 | 能干什么 |
|---|---|---|
| **合成升级卡** | 最多 5 个配方（3×3 幽灵格 + 产物） | 自动合成（检验合成表里真实存在的配方） |
| **机械手卡片** | 手上物品 + 输入物品（左右键自动判断，不攻击） | **斧头 + 原木 → 去皮原木**；**安山合金 + 去皮原木 → 安山机壳** |
| **动力锯卡片** | 输入物品 + 选定产物 | 切割：原版切割 + **机械动力的 `create:cutting`**（一次多产物全部放回） |

- 物品应用是**直接读数据包里的 Create `item_application` 配方**，不依赖 Create 代码 → 任何模组的"物品按到方块上"配方都能跑
- 配置界面**带玩家背包**，没装 JEI 也能从背包拿物品点进格子；装了 JEI 还能直接拖
- 目标多了可以**滚轮翻列表**

## 二、防小偷

- **取用记录**：左侧栏「取用记录」按钮 → 可滚动列表，记录**谁**、**拿了什么**、**拿了多少**、哪个仓库、什么时间
  - 共享仓库：任何人取用都记（普通点击 + **shift-click 都记**）
  - 私人仓库：只记非主人的取用
  - 最多 300 条，存进存档
- **输出方块显示放置者**：方块界面显示「放置者：xxx」

## 三、配置

- **`enable_shared_warehouse`**：可以整体关掉共享大仓库（界面不显示、方块不能指向、服务端拒绝）
- 配置文件顶部和各开关都写了中文备注

## 四、这轮自查出的 4 个 bug（已修）

| # | 问题 | 后果 |
|---|---|---|
| 1 | 卡槽 `mayPlace` 只认「合成升级卡」 | **机械手/动力锯卡片根本放不进卡槽** |
| 2 | `CreateRecipes` 用"配方非空"判断已加载 | 没装 Create 时会**每 0.5 秒重扫一遍全部配方 JSON** |
| 3 | 记录界面 `init()` 里发请求 | 服务端回包 → 开新界面 → 又请求 → **无限循环刷屏** |
| 4 | shift-click 拿东西不触发 `onTake` | **能绕过取用记录** |
