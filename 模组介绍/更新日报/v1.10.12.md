# v1.10.12 更新日报

**日期**：2026-10-07
**类型**：改名（中间物品定名）
**jar**：`mcmcp_warehouse-1.10.12.jar`

## 改动

1.10.11 里那个中间物品原来叫「**合成核心**」，但它的用途不止卡片 ——
以后要做的**机械手 / 动力锯**之类的自动化设备也会拿它当材料之一，
所以名字要通用，改名为「**自动化核心**」（`automation_core`）。

同步改的地方：

| 项 | 内容 |
|---|---|
| 物品 id | `commhub:crafting_core` → `commhub:automation_core` |
| 显示名 | 合成核心 → **自动化核心**（英文 Automation Core） |
| 贴图 / 模型 / 语言 | 全部改名 |
| 配方文件 | `automation_core.json`（含原版兜底） |
| 配方图 | 单图改名 `recipe_automation_core.png`，总图与手册引用同步 |
| 手册 / 使用指南 md | 文案、图片引用、配方表全部同步 |
| 字体 | 配方图字体补了「自动化核心」5 个字（现 48 字） |

> 以后做机械手、动力锯时，直接用 `commhub:automation_core` 当材料即可。
