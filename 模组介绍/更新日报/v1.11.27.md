## 1. 自查出的 bug：多条物品时**还是显示内部 id**
v1.11.26 我加了 `prettyItems()` 把 `3×create:cogwheel` 翻译成 `3×齿轮`，
但它按**逗号**拆分，而服务端拼多条物品用的是 **`" + "`** ✗
→ 悬赏里有 2 件以上物品时，解析失败，**照样显示 create:cogwheel** ✗

**两处一起修**：
- **服务端**：发给客户端的展示串直接用 `getHoverName()`（游戏内名字）—— 那个串本来就只用于显示
- **客户端**：`prettyItems` 的拆分支持 `" + "` 和逗号两种（兼容老数据）

顺手还改了两个小地方：
- 顶部提示太长会超出面板 → 缩短成「左键放物品 / 滚轮调数量 / Shift×64 / 右键清空」
- 格子上的大数量用压缩显示（不会写一长串 0）

## 2. 以物换物说明重写（手册 + md）
原来手册里还写着「滚轮调数量（可到 999999）」这种过时说法，步骤也不清不楚 ✗

**手册两条目重写（中英）**：
- 《以物换物：发布悬赏》4 页：在哪 → 怎么填（我给/我要、10 格、左键/滚轮/Shift/右键）→ 发布（不扣物品）→ 成交条件
- 《以物换物：接受悬赏》3 页：在哪（换物模式）→ 怎么看（◀▶、显示游戏内名字）→ 接受（自动交换 + 回滚保护）

**使用指南 md 第七节重写**：表格 + 步骤 + 成交条件，并补齐「每人最多 5 条」这类实际规则。
