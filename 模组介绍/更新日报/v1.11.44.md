## 用户反馈
> 「还有锁链是竖着，不是横着的 bug」

## 找到真凶：**链节实体**（那 4 个碰撞体）
| 位置 | 原来 | 结果 |
|---|---|---|
| 主链子 | 按锁链走向自动选轴 | 门在**斜上方**时 **Y 会赢** → 链环竖着 ✗ |
| **链节实体** | 直接用 `Blocks.CHAIN.defaultBlockState()` | **默认就是 AXIS=Y（竖的）** ✗✗ |

## 改法：统一用一个「水平链环」方法
```java
private static BlockState chainStateHorizontal(double dx, double dz) {
    Axis axis = (Math.abs(dx) >= Math.abs(dz)) ? Axis.X : Axis.Z;
    return Blocks.CHAIN.defaultBlockState().setValue(ChainBlock.AXIS, axis);
}
```
- **主链子**：用锁链方向的水平分量 `(dir.x, dir.z)` ✓
- **链节实体**：用「本链节 → 最近玩家」的水平方向 ✓

→ **所有链环一律横着** ✓
