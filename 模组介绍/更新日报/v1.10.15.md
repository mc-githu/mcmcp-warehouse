# v1.10.15 更新日报

**日期**：2026-10-07
**类型**：新功能（自动化任务真正跑起来了）
**jar**：`mcmcp_warehouse-1.10.15.jar`

## 改动：卡片接上真正的自动化配方

### 机械手卡片（两个格子）
配置：**手上物品**（工具/材料）+ **输入物品**（被加工的）。**左右键自动判断**，不攻击。

| 配置 | 结果 |
|---|---|
| **斧头 + 原木** | → **去皮原木** |
| **安山合金 + 去皮原木** | → **安山机壳** |

- 去皮：按原版/多数模组的命名规律（`oak_log` → `stripped_oak_log`）
- 物品应用：直接读数据包里 Create 的 `item_application` 配方（**不依赖 Create 代码**），所以任何模组的"物品按到方块上"配方都能跑

### 动力锯卡片（两个格子）
配置：**输入物品** + **选定产物**。现在支持两类切割配方：
- 原版切割（Stonecutting）
- **机械动力的 `create:cutting`**（原木 → 木板 等，一次多个产物全部放回仓库）

### 其它
- 机械手 / 动力锯卡片的配置界面统一成**两个格子**（不再有"左键/右键"按钮，改成自动判断）
- 手册条目、说明文字同步

## 说明
- 卡片节奏和合成卡一致：每约 **0.5 秒**干一次活
- 材料从仓库取、产物放回仓库；材料不够就停
