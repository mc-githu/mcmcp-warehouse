## 发版流程提醒

**改了版本号之后，必须强制重建**，否则 gradle 会因 up-to-date 不产出新 jar：

```bash
gradle build --no-daemon --rerun-tasks --init-script init.gradle
```

装之前先确认 `build/libs/mcmcp_warehouse-<新版本>.jar` 存在 ✓

## 版本号规则

格式固定为 `1.<大更新序号>.<本轮修bug次数>`：

| 事件 | 变化 | 例子 |
|---|---|---|
| 一次大更新（加功能） | 中间位 +1，**末位清零** | 1.10.15 → **1.11.0** ✅ 本版 |
| 一次修 bug | 末位 +1 | 1.9.11 → 1.9.12 |
| 末位不进位 | 本轮修 N 个就是 `.N` | 本轮修 20 个 = `1.9.20` |
| 计数只在本轮累计 | 下次大更新时归零 | 1.9.20 → 1.10.0 |

> 例：第 10 次大更新那一轮修了 20 个 bug → `1.10.20`
