# v1.11.41 更新日报

**日期**：2026-10-09
**类型**：修复（包裹不从门里出来）

## 用户反馈
> 「包裹应该是从门里面出来到我身上了，怎么没出来一直挂在我身上了，直接就挂我身上了，
>   而不是从门中间出来」

## 根因
你测的是 **`/commhub rift`（常驻）**。
常驻模式下我的 `progress()` **永远返回 1** ✗
→ 进度直接到终点 → 包裹就"定"在你身前 85% 的位置不动 ✗
所以看着像"一上来就挂你身上"，而不是从门里出来 ✓

## 修复
**常驻时进度改成循环播放**：
```java
int cycle = 110;                 // 5.5 秒一轮
int t = (int) ((age + partialTick) % cycle);
float f = t / (float) cycle;
return f < 0.7f ? f / 0.7f : 1f; // 70% 时间走完，剩下停在门口
```
于是常驻裂缝里：包裹会**反复从门中间出来 → 沿锁链走到你身前 → 回到门里** ✓
（锁链一直伸着不收回 ✓）

同时确认包裹路径：**起点 = 门中心（pk=0）**，终点 = 身前 85% ✓
→ 进来时就是从门中间冒出来 ✓
