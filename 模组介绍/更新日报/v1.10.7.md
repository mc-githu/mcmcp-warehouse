# v1.10.7 更新日报

**日期**：2026-10-07
**类型**：修复（**断连崩溃**）
**jar**：`mcmcp_warehouse-1.10.7.jar`

## 现象

右键卡片打开配置界面时**直接断连**（`debug/disconnect-*.txt`）：

```
Description: Packet handling error
java.lang.NullPointerException: Cannot invoke "FriendlyByteBuf.readInt()" because "buf" is null
    at com.commhub.CraftingCardMenu.<init>(CraftingCardMenu.java:36)
    at IContainerFactory.create -> MenuType.create -> MenuScreens.create
```

## 原因

1.10.6 把配置界面改成「带背包的容器界面」时，用 `SimpleMenuProvider` 打开菜单
**却没有写额外数据**，客户端拿到的 `buf` 就是 `null`，而构造函数直接 `buf.readInt()` → NPE。

（模组里其它菜单都写了 buf，只有这个新菜单漏了。）

## 修复

1. 打开菜单时把「主手/副手」写进数据包：`openMenu(provider, buf -> buf.writeInt(hand))`
2. 构造函数加空值保护：`buf == null ? 0 : buf.readInt()`（双保险）
3. 顺手检查了模组里**全部 6 处 `openMenu`**，确认其它都有写 buf，没有同样的隐患
