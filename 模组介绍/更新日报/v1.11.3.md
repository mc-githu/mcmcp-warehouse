# v1.11.3 更新日报

**日期**：2026-10-08
**类型**：修复（**两张新卡片完全没被执行**）
**jar**：`mcmcp_warehouse-1.11.3.jar`

## 问题

用户反馈：**机械手卡片和动力锯卡片都没用**（合成升级卡正常）。

## 根因

定时任务里只调了一个方法：

```java
for (HubSavedData.PrivateWarehouse w : data.allPrivateWarehouses()) {
    AutoCrafter.tick(level, w.storage, w.cardSlots);   // ← 只有合成升级卡
}
```

**`tickSaw`（动力锯）和 `tickDeployer`（机械手）的调用在后续某次改动中被覆盖掉了**，
所以两张新卡片**永远不会被执行** —— 这也解释了为什么只有这两张没用、合成卡一直正常。

## 修复

把三个调用都接回来：

```java
for (HubSavedData.PrivateWarehouse w : data.allPrivateWarehouses()) {
    AutoCrafter.tick(level, w.storage, w.cardSlots);         // 合成升级卡
    AutoCrafter.tickSaw(level, w.storage, w.cardSlots);      // 动力锯卡片（切割 / 去皮）
    AutoCrafter.tickDeployer(level, w.storage, w.cardSlots); // 机械手卡片（物品应用）
}
```

并全项目扫了一遍，确认没有其它"方法写了但没接上"的情况。

> 教训：这种"新功能没接线"的问题最难发现，之后每次加卡片都会顺手确认 ticker 里有没有对应调用。
