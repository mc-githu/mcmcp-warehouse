# v1.11.11 更新日报

**日期**：2026-10-08
**类型**：界面修复 + 默认值调整 + 记忆标签页
**jar**：`mcmcp_warehouse-1.11.11.jar`

## 1. 取用记录界面看不清 —— 两个真 bug

### bug A：颜色代码被当普通文字画出来了
原来服务端把记录拼成带 `§f/§7/§8` 颜色代码的字符串发过来，
客户端用 `drawString(String)` 画 —— **这个方法不解析颜色代码**，
所以你看到的是 `§f玩家名 §7拿走了 §f...` 这种乱码，根本没法读。

**改法**：数据包改成**结构化数据**（玩家名 / 物品 / 数量 / 仓库 / 时间分别发），
客户端用 `Component` 自己上色：

```
玩家名(金) 拿走了 物品(白) ×数量(黄)  仓库(深灰) 时间(深灰)
```

### bug B：后面是"模糊的世界"
界面调用了 `renderBackground()` —— 那是原版的**模糊背景**效果，
再叠上半透明面板 → 后面发虚，按钮像浮在别的东西上。

**改法**：自己铺**不透明**底（全屏 + 面板 + 列表区各自实色），不再用 `renderBackground()`。
另外加了**隔行斑马纹**和滚动条，一行一行看得清。

## 2. 共享大仓库默认关闭
配置 `enable_shared_warehouse` 默认值 **true → false**（需要的话自己去配置里打开）。

## 3. 打开界面会回到上次那个标签页
以前按 K 总是从默认页打开，每次都要翻半天。现在：

- 关闭界面 / 切换标签页时**记住**（含私人仓库名字）
- 存在客户端配置 `config/commhub-client.toml`
- 下次按 K **直接回到上次那个标签页**（重启游戏也记得）

如果上次看的是私人仓库，会先校验你还有没有权限；没有就自动退回可用的仓库。
