## 所以加了自检指令（游戏内一条命令验证）

```
/commhub loottest          # 各掷 100 次
/commhub loottest 1000     # 掷 1000 次，更稳
```

输出：

```
【战利品自检】各掷 100 次
· 注入表 commhub:inject/automation_core：核心 X 次（期望约 20）
· 地牢宝箱 minecraft:chests/simple_dungeon：共 Y 件，其中核心 Z 次（期望约 20）
→ §a注入生效 ✓   /   §c宝箱里一次都没出 → 修改器没生效
```

判定逻辑：
- `X = 0` → **子表本身有问题**
- `X > 0` 但 `Z = 0` → **战利品修改器没生效**（注入没接上）
- `Z > 0` → **真的能用** ✅

结果同时写进日志。
