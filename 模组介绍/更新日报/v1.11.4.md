# v1.11.4 更新日报

**日期**：2026-10-08
**类型**：修复（机械手卡片不工作）
**jar**：`mcmcp_warehouse-1.11.4.jar`

## 问题

机械手卡片不工作。

## 修复

### 1. 改成「只能右键」（按用户要求）
机械手卡片现在**只做右键动作**：把手上物品按到输入物品上（Create 的 `item_application`）。
- 去掉了"斧头去皮"那条分支（去皮是**动力锯卡片**的活）
- 不做攻击、不做破坏

### 2. Create 配方读取改成全量扫描（关键）
之前按**路径前缀**过滤（`item_application/`、`cutting/`）来挑配方文件，
这个假设如果不对，就会**一条配方都读不到** → 物品应用自然找不到配方、卡片不动。

现在改成：**扫描全部 recipe JSON，按文件里的 `type` 字段判断**
（`create:item_application` / `create:cutting`），不再依赖路径拼法。

### 3. 诊断日志写清楚
机械手卡片匹配不上时，日志里会直接说明：

```
机械手卡片（只做右键/物品应用）：没匹配上。手上=安山合金，输入=去皮橡木原木；
已读到物品应用配方 0 条；仓库里缺[安山合金]
```

这样能一眼看出是**配方没读到**、还是**仓库里缺材料**。

启动时也会打一条：

```
[commhub] 读到 Create 加工配方：切割 N 条，物品应用 M 条（共扫了 X 个配方文件）
```
