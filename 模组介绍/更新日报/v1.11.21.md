## 关键线索（用户提供）
> 「不是，是只有查看那个拿取记录的时候才模糊」

这一句直接锁定了范围：**其它界面都正常**，只有取用记录模糊。

## 对比找到了唯一差异

把「无容器界面」逐个对比：

| 界面 | 画背景的方式 | 是否模糊 |
|---|---|---|
| 好友列表 / 新建仓库 / 仓库列表 | **什么都不铺**（世界直接透出来） | ❌ 不模糊 |
| 取用记录 | **铺了一层全屏不透明底** `g.fill(0,0,width,height,...)` | ✅ 模糊 |

**取用记录是唯一铺全屏底的界面，也是唯一模糊的。**

（之前我折腾 `renderBackground`/模糊后处理/纯黑/半透明渐变，全都是在错误的方向上 —— 真正的问题就是这句全屏 fill。）

## 修复
去掉那句全屏底，改成和好友列表等界面**一致**：不铺全屏底，只画**面板本身**（面板仍是实色，文字照样清楚）。

```java
// 原来（只有它这么干）
g.fill(0, 0, this.width, this.height, 0xFF07070A);
g.fill(left, top, left + PANEL_W, top + PANEL_H, 0xFF17171E);

// 现在（与其它界面一致）
g.fill(left, top, left + PANEL_W, top + PANEL_H, 0xF017171E);
```

## 说明
这一版**没有**动任何游戏设置、也没有改其它界面。
