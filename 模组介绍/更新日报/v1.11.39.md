# v1.11.39 更新日报

**日期**：2026-10-09

## 用户问
> 「所以实际中使用的时候可以吗？」

**老实说：之前不行。** ✗
真实成交（`performTrade`）发的是**旧的 GUI 屏幕动画**包，
新的 **3D 实体版**只有 `/commhub rift [play]` 会触发 →
正常交易时看到的是旧版，不是这套 3D 动画。

## 修复：成交也走 3D 实体动画
`performTrade` 里那 4 个 GUI 动画包，换成**在双方各自面前开一个裂缝**：

```java
spawnRiftFor(owner,    fxWant,  namesOf(trade.want()));   // 发布者收到的东西
spawnRiftFor(accepter, fxOffer, namesOf(trade.offer()));  // 接受者收到的东西
```

- 裂缝位置：玩家**正前方 2.5 格**，正面朝向玩家 ✓
- 包裹里是**收到的物品**，上方提示**物品名**（多个用「、」连接，超过 3 样加「…」）✓
- 从此**正常交易**和调试指令走的是**同一套 3D 动画** ✓
