# mcmcp 的仓库

> Minecraft **1.21.1** · **NeoForge** · modId `commhub`

把「共享仓库 / 私人仓库 / 好友私聊 / 传物品 / 以物换物」整合进一个界面的仓库模组。
按一个**可配置的按键**打开主界面，所有功能都在里面。

---

## 下载（重要）

**打包好的 jar 全部发布在仓库的 Releases 页面**，从最早的 `v0.10.0` 一直到最新的 `v1.11.44`，一个版本一个 Release。

> ⚠️ **仓库里不放 jar**，只有源码和文档。要玩请到 **Releases** 页面下载对应版本。

- 想要最新版 → 打开 Releases 页面找版本号最大的那个
- 安装 → 把 jar 放进 `.minecraft/mods/`（需要 NeoForge 1.21.1 客户端/服务端）
- 服务端和客户端都要装（模组主要逻辑在服务端）

## 从源码构建

需要 **JDK 21** 和 **Gradle 8.x**：

```bash
cd mcmcp的仓库源码
gradle build
```

产物位于 `mcmcp的仓库源码/build/libs/mcmcp_warehouse-<版本>.jar`。

编译期依赖 **JEI** 和 **Patchouli** 已放在 `mcmcp的仓库源码/libs/`（标记为 `compileOnly`，不会打进 jar）。

## 版本号规则

格式为 `1.<大更新序号>.<本轮修 bug 次数>`：

| 事件 | 变化 | 例子 |
|---|---|---|
| 加功能（大更新） | 中间位 +1，末位清零 | `1.9.7` → `1.10.0` |
| 修 bug | 末位 +1 | `1.9.6` → `1.9.7` |
| 修 bug 计数 | 只在本轮累计，下次大更新归零 | 本轮修 20 个 → `1.9.20` |
